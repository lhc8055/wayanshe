隐私政策
生效日期：2026年11月28日  |  更新日期：2026年11月28日

瓦研社（域名：wayanshe.xyz，以下简称“本站”）深知个人信息对您的重要性。本政策将详细说明我们如何收集、使用、存储、共享和保护您的个人信息，以及您享有的法定权利。

本政策适用于您通过QQ或微信登录并使用本站的全过程。请您在登录前仔细阅读本政策。涉及手机号强制绑定、数据存储于境外基础设施等关键内容，我们已以高亮加粗形式提示。

一、 我们收集哪些个人信息

我们遵循合法、正当、必要和诚信原则，仅收集实现具体功能所必需的信息。

1. 第三方快捷登录信息：当您通过QQ或微信授权登录本站时，我们从腾讯相应服务接收：您在该平台的用户唯一标识（OpenID 或 UnionID）、昵称、头像。我们绝对不会获取您的QQ/微信密码、好友列表或聊天记录。

2. 手机号码（敏感个人信息）：首次登录后，您需要绑定中国大陆手机号码。用途严格限于：(1) 满足网络实名制相关法律法规要求；(2) 账号安全验证与找回；(3) 处理投诉时进行身份核验。我们郑重承诺：手机号仅用于上述目的，绝不用于营销推广，绝不向任何第三方出售或出租。如您拒绝绑定，将无法使用收藏、评论、投稿等互动功能，但不影响浏览公开攻略。

3. 互动内容数据：当您发布评论、投稿攻略、收藏点位时，我们会存储您主动提交的文字、图片、时间戳及关联账号标识。请注意，您公开发布的内容可能被其他用户或搜索引擎抓取，请勿在公开内容中填写个人隐私。

4. 日志与设备信息：为保障基本运行与安全，我们的基础设施服务商（如Cloudflare）会自动记录访问日志，包括IP地址、浏览器类型、访问时间等。我们本身不主动构建用户画像，不将日志用于广告投放。

二、 我们如何存储您的个人信息（跨境说明）

您的个人信息存储于以下基础设施中：

服务商 存储内容 所在区域
Supabase 账号标识、昵称、手机号、发布内容等业务数据 境外云基础设施 (如美国/新加坡)
Cloudflare 访问日志、网络请求信息（CDN加速与防护） 全球网络（含境外节点）
GitHub 前端代码部署相关技术日志 境外平台

重要提示：由于Supabase和Cloudflare的境外基础设施涉及个人信息出境。您的账号标识、手机号和发布内容可能被传输至位于中华人民共和国境外的服务器进行存储和处理。我们已通过签订适用的数据传输协议或标准合同条款来保障您的数据安全。

存储期限：我们仅在实现目的所需的最短期限内保留您的信息。账号注销后，除法律法规要求保留的（如日志留存）外，我们将删除或匿名化您的个人信息。

三、 我们如何共享您的信息

我们不会向任何第三方出售您的个人信息。仅在以下情形下共享或委托处理：

1. 委托处理：我们委托 Supabase、Cloudflare、GitHub 处理上述数据，他们仅作为受托方按照我们的指示提供服务，不得将数据用于其自身商业目的。

2. 第三方登录独立性：QQ和微信登录由深圳市腾讯计算机系统有限公司提供。您在腾讯侧的隐私处理适用腾讯的隐私政策，本站仅接收登录必需的标识、昵称和头像。

3. 法定情形：根据法律法规、司法或行政机关强制性要求，或为维护公共利益及您本人重大合法权益所必需时。

四、 您对个人信息的权利

根据《个人信息保护法》，您享有以下权利：

  • 查阅、复制权：您可在账号设置中自行查看，或通过邮箱申请副本。
  • 更正、补充权：昵称头像可重新授权更新；手机号可申请换绑。
  • 删除权：您可自行删除发布的内容，或申请注销账号以清空数据。
  • 撤回同意权：您有权撤回对手机号处理的同意。但撤回同意将导致您无法继续使用需登录的互动功能。

我们将在收到请求并验证身份后15个工作日内予以答复；情况复杂的，可延长至30个工作日。

五、 未成年人保护

1. 本站主要面向游戏玩家。若您是不满十四周岁的儿童，请绝对不要绑定手机号或使用本站需要登录的功能。我们不会在未取得监护人同意的情况下主动收集儿童个人信息。

2. 若您是已满十四周岁但未满十八周岁的未成年人，请在监护人指导下阅读本政策，并在取得监护人同意后使用。

3. 如监护人发现我们在未事先取得同意的情况下收集了儿童信息，请通过本政策邮箱联系我们，我们将尽快删除。

六、 信息安全与免责

1. 我们采取与风险相适应的技术措施（如Supabase的访问控制、Cloudflare的传输加密）保护您的信息。

2. 但请注意：任何互联网传输和存储方式都无法保证100%绝对安全。因黑客攻击、网络基础设施故障（如Supabase或Cloudflare宕机）、不可抗力导致的个人信息泄露、丢失或篡改，本站已尽到合理保护义务的，不承担法律责任。如发生安全事件，我们将按法律要求及时告知您及主管部门。
